# Tài liệu tham chiếu cũ

`v1_11_0/` giữ bảng Excel/CSV/txt đã bàn giao trước đây để đối chiếu numeric MQTT. Không tự sửa file cũ thành phiên bản mới và không coi đó là kiểm chứng1.12.

Hướng dẫn hiện hành: [MQTT](../../docs/MQTT.md), [Modbus](../../docs/MODBUS.md), [commands](../../docs/COMMANDS.md). Source/SDK/contract1.12 nằm trong cùng package, không cần source1.11 để build.
